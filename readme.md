# App Seminario - Flask CI/CD

Este es un proyecto académico de una aplicación web básica construida con **Flask**. El objetivo principal de este repositorio es demostrar la implementación de un flujo de Integración Continua (CI) utilizando **GitHub Actions**.

## Estado del Proyecto
![CI/CD Status](https://github.com/ale948/app-seminario/actions/workflows/ci.yml/badge.svg)

## Características
* Aplicación web con Python y Flask.
* Pruebas automatizadas (Testing).
* Análisis de calidad de código con `flake8`.
* Pipeline de CI/CD configurado con GitHub Actions.

## Requisitos
Para ejecutar este proyecto localmente, necesitas tener instalado:
* Python 3.x
* pip (Administrador de paquetes de Python)
